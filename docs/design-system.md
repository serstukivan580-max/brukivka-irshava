# Дизайн-система (версія 2)

## Кольори (`:root` у `css/style.css`)
| Токен | Значення | Призначення |
|---|---|---|
| `--bg` | `#F6F4F0` | основний фон (теплий кам'яний білий) |
| `--bg-alt` | `#EDE9E2` | фон чергових секцій |
| `--surface` | `#FFFFFF` | картки |
| `--ink` | `#141414` | текст, темні кнопки |
| `--muted` | `#6A665F` | другорядний текст (≈5:1 на фоні) |
| `--dark` | `#151514` | темні секції, блок результату |
| `--accent` | `#B48C4F` | бронзовий акцент, головні кнопки |
| `--accent-ink` | `#84642F` | акцентний текст на світлому (AA) |

## Шрифти
- Заголовки: **Inter Tight** 600/700, щільний трекінг (-0.02…-0.03em).
- Текст: **Inter** 400/500/600.

## Компоненти
- Кнопки-пігулки: `btn--accent`, `btn--dark`, `btn--glass` (на фото), `btn--outline`.
- Картки з радіусом 14px і м'якою тінню.
- Мітки секцій (`.kicker`) — uppercase + бронзова риска.

## Брейкпоінти
1200 · 1024 (мобільне меню) · 720 (телефон, нижня панель дій) · 380
