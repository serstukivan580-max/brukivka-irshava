# Сайт «Викладка бруківки · Іршава»

## Як відкрити
Двічі клацніть `index.html` — сайт відкриється в браузері. Нічого встановлювати не треба
(для шрифтів і карти потрібен інтернет).

## Що на сайті
1. Головний екран з великим фото та **швидким розрахунком** (площа + тип → сума).
2. Послуги (4 картки з фото).
3. «Чому не просідає» — про основу й трамбування.
4. Каталог бруківки з цінами за м² (кнопка «Порахувати» відкриває калькулятор з цим типом).
5. **Калькулятор**: площа або довжина × ширина, тип, товщина, демонтаж, ґрунт, основа, бордюр, водовідвід, свій/наш матеріал. Розбивка суми, ціна за м², «Надіслати розрахунок».
6. **До / Після** — повзунок + перемикач між 3 об'єктами.
7. Етапи роботи, галерея ідей (фото відкриваються на весь екран), блок TikTok, питання, контакти з картою Іршави.

## Де що міняти — тільки `js/config.js`
- `prices` — ціни. Зараз **демо-ціни**. Впишіть свої й поставте `isDemo: false`
  (зникне примітка «Ціни на сайті поки демонстраційні»).
- `tiles` — типи бруківки (назва, опис, фото).
- `works` — пари «До / Після», назви та підписи (`meta`, напр. `'85 м² · «Старе місто»'`).
- `worksAreStock` — поставте `false`, коли заміните фото «До/Після» своїми (зникне примітка «Ілюстративні фото»).
- `reviews` — тільки справжні відгуки: `{ name: 'Іван, Іршава', text: '...' }`.
  Поки список порожній, замість відгуків показується блок TikTok.

## Фото
Усі фото — з Unsplash (безкоштовна ліцензія, можна для комерції, без обов'язкового зазначення автора).
**Це не ваші об'єкти.** Для довіри клієнтів найкраще замінити їх своїми фото з тими самими іменами файлів у папці `images/`:

| Файл | Де на сайті |
|---|---|
| `hero.jpg` | головний екран (горизонтальне, 2000+ px) |
| `service-sale.jpg`, `service-laying.jpg`, `service-base.jpg`, `service-curb.jpg` | картки послуг (4:3) |
| `project-house.jpg` | блок «Чому не просідає» (вертикальне 4:5) |
| `tile-brick.jpg`, `tile-oldtown.jpg`, `tile-slab.jpg`, `tile-granite.jpg` | каталог і калькулятор (квадрат) |
| `before-1..3.jpg`, `after-1..3.jpg` | «До / Після» — **один ракурс** до і після |
| `idea-1..6.jpg` | галерея ідей |
| `after-2.jpg` | також фон блоку контактів |

У вашому TikTok уже є пари «щебінь → готова бруківка» біля тих самих будинків — вони ідеально підійдуть для «До / Після».

## Що уточнити у власника
- Реальні ціни.
- Чи справді замір безкоштовний (так написано на кнопках).
- Чи є мінімальна сума замовлення (`minOrder`).

## Тести калькулятора
Запустіть локальний сервер і відкрийте `http://localhost:5510/js/calculator.test.html` — має бути «Пройдено 12 з 12 ✅».
```
python -m http.server 5510
```

## Як викласти в інтернет (безкоштовно)
1. https://app.netlify.com/drop
2. Перетягніть туди всю папку `плитка`.
3. Отримане посилання вставте в профіль TikTok.

## Структура
```
index.html               сторінка
css/style.css            стилі
js/config.js             НАЛАШТУВАННЯ: ціни, телефон, фото, відгуки
js/calculator.js         логіка розрахунку (чисті функції)
js/calculator.test.html  тести
js/before-after.js       блок «До / Після»
js/main.js               меню, швидкий розрахунок, калькулятор, галерея, анімації
images/                  фото
docs/                    концепція та дизайн-система
```
